## Interactive Elements

### Progress Bar States
- **Animated Blue** - Translation actively running
- **Static Green** - Translation completed successfully
- **Static Red** - Translation failed
- **Static Yellow** - Translation cancelled

### Buttons
- **[Download All Files]** - Downloads all translated documents
- **[Delete Temporary Files]** - Cleans up storage
- **[Retry Failed Files]** - Re-attempts failed documents
- **[Start New Translation]** - Begins fresh translation

## Print-Friendly

When printed, the status page shows:
- Job ID
- Current status
- Document statistics
- Timestamps
- Error messages (if any)
- Removes animations and interactive elements
